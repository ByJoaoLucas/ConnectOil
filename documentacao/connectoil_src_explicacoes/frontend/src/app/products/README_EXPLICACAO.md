# Pasta: `frontend/src/app/products`

## Visão Geral
Rota `/products` para gestão do catálogo de produtos disponíveis para troca por óleo coletado (fluxo de permuta/bonificação).

## Arquivos (1 arquivo)
- **`page.tsx`**: Gerencia produtos (`productsApi`) com categoria, unidade de medida, preço por unidade, estoque atual, estoque mínimo (com alerta de estoque baixo), ativação/desativação e ajustes rápidos de movimentação de estoque (`updateStock`).
