# Pasta: `backend/src/main/java/com/oilcollection`

## Visão Geral
Contém a classe principal de inicialização da aplicação Spring Boot (`OilCollectionApplication.java`) e serve como pacote raiz para todas as camadas do domínio de gestão de coleta de óleo (`com.oilcollection.*`).

## Arquivos
- **`OilCollectionApplication.java`** (~585 B): Ponto de entrada (`main`) anotado com `@SpringBootApplication`, responsável por disparar o contexto Spring, varrer componentes/entidades e iniciar o servidor embebido.
