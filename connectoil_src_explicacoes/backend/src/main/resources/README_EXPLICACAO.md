# Pasta: `backend/src/main/resources`

## Visão Geral
Armazena arquivos de configuração da aplicação Spring Boot e recursos estáticos/SQL empacotados no artefato backend.

## Arquivos e Subpastas
- **`application.yml`**: Configurações principais da aplicação (datasource, JPA/Hibernate, Flyway, porta, JWT e variáveis de ambiente).
- **`db/migration/`**: Subpasta contendo os scripts SQL versionados de evolução do banco de dados.
